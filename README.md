# DecodeLabs Data Analytics Internship
### Batch 2026 | Projects 1, 2 & 3

## Overview
This repository contains all three Data Analytics 
projects completed during the DecodeLabs Industrial 
Training Internship. Each project builds on the 
previous, covering the full data analytics pipeline 
from raw data to business insights.

---

## Project 1: Data Cleaning & Preparation 🧹
Tool: Microsoft Excel  
Dataset: 1,200 sales orders  

### What I did:
- Identified and handled missing values
- Removed duplicate records
- Corrected data formats (dates, numbers, text)
- Filled null CouponCode values with "No Coupon"

### Outcome:
Delivered a clean, analysis-ready dataset with 
1,200 valid records and zero errors.

---

## Project 2: Exploratory Data Analysis 📊
Tool: Microsoft Excel (Pivot Tables + Dashboard)  

### What I did:
- Calculated basic statistics (mean, median, 
  min, max) for all numeric columns
- Identified monthly sales trends
- Analyzed performance by product, payment 
  method and order status
- Detected outliers using IQR method
- Built an interactive dashboard with 5 charts

### Key Findings:
- Chair & Printer are top revenue products (~$195K)
- Sales peak in June and drop sharply from July
- Cancelled orders ($276K) exceed delivered 
  orders ($242K) — a critical business risk
- 8 high-value outlier orders identified above $3,330

---

## Project 3: SQL Data Analysis 🗄️
Tool: SQL Server (SSMS) + GitHub  

### What I did:
- Created SalesD database from scratch
- Built staging table and used BULK INSERT 
  to load raw CSV data
- Converted all data types using TRY_CAST
- Wrote EDA queries using SELECT, WHERE, 
  GROUP BY, ORDER BY
- Used COUNT, SUM, AVG aggregations

### Queries Written:
1. Total revenue by product
2. Order count by payment method
3. Average order value by product
4. High-value orders (TotalPrice > $3,000)
